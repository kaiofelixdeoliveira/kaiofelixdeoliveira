## 👋 Sobre mim

Construo e lidero a construção de **sistemas de backend que precisam ficar de pé**: alto volume, integrações assíncronas e times que mudam ao longo do caminho. Minha régua não é "funcionou na minha máquina" — é entregar software que o próximo time consegue evoluir.

- 🏗️ **Arquitetura e liderança técnica** — desenho de serviços em Java/Spring Boot com Clean Architecture e SOLID, priorizando limites claros entre domínio e infraestrutura.
- 🔄 **Integrações event-driven** — mensageria com Apache Kafka e RabbitMQ, além de APIs REST e SOAP para integrar sistemas legados sem travar a evolução do produto.
- ☁️ **Cloud &amp; DevOps** — AWS e Azure DevOps, com pipelines de CI/CD que tiram o deploy do caminho crítico do time.
- 📱 **Produto ponta a ponta** — quando necessário, desço do backend para o front (React, Angular) e para o mobile (Flutter), entregando o que o usuário de fato usa.
- 🤝 **Decisões técnicas explícitas** — trade-offs documentados, code review como parte da entrega e mentoria de devs mais novos.

> 🔭 **Hoje:** desenvolvendo um ecossistema de saúde e nutrição (API, app mobile e painel web para profissionais), com apoio de IA no acompanhamento do paciente.

### 👋 About me

I build — and lead the building of — **backend systems that have to stay up**: high volume, asynchronous integrations, and teams that change along the way. My bar isn't "works on my machine"; it's shipping software the next team can actually evolve.

- 🏗️ **Architecture &amp; technical leadership** — Java/Spring Boot services designed around Clean Architecture and SOLID, with clear boundaries between domain and infrastructure.
- 🔄 **Event-driven integration** — Apache Kafka and RabbitMQ messaging, plus REST and SOAP APIs to integrate legacy systems without blocking product evolution.
- ☁️ **Cloud &amp; DevOps** — AWS and Azure DevOps, with CI/CD pipelines that keep deployment off the team's critical path.
- 📱 **End-to-end product** — when needed, I go from the backend down to the front-end (React, Angular) and mobile (Flutter), delivering what users actually touch.
- 🤝 **Explicit technical decisions** — documented trade-offs, code review as part of delivery, and mentoring of junior developers.

> 🔭 **Currently:** building a health and nutrition ecosystem (API, mobile app and web dashboard for professionals), using AI to support patient follow-up.
